# F-Droid — projeto transferido para a edição independente

Desde 14/10/2026, o candidato ao F-Droid é **Bíblia Livre IPM**, application ID `br.com.valdenor.biblialivreipm`.

- [Código e README](https://github.com/alunoadsnoite/biblia-livre-ipm)

- [Pedido existente #4547](https://gitlab.com/fdroid/rfp/-/work_items/4547)

A release 5.5.0 deste repositório é uma etapa intermediária, ainda com Biblioteca e com o identificador da igreja. A afirmação anterior de que todas as pendências de licença estavam resolvidas era ampla demais: a antiguidade das obras originais não comprova direitos de traduções modernas, e ainda faltam evidências exatas de origem para alguns textos.

A edição independente remove os documentos da Biblioteca. A aprovação e a publicação no catálogo oficial continuam pendentes de avaliação dos mantenedores.

Solicitação de empacotamento existente: [fdroiddata !52559](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/52559), ainda em avaliação.
